# 详细材料 `handout.md`

听众散场后唯一能带走的东西。**判断标准：一个没来现场的人，读它能不能懂。**

## 它不是什么

- 不是讲稿（不写「我先停一下」「大家看这张表」）
- 不是 slides 的文字版（不写「一屏一件事」的短句）
- 不是提纲（不做只有标题和要点的骨架）

它是**一篇能独立成立的长文**，只是恰好按讲台顺序组织。

## 结构

```markdown
# 示例分享：从认知到实操

> 本文配合 90 分钟现场分享整理。讲座中的演示与现场操作，在文中标注了对应位置。

## 〇、先明确三个前提

### 这份材料回答什么问题

……（一段话，把读者拉进来，说明读完能得到什么）

### 谁适合读，谁可以跳过

……

## 一、术语：六个词各指什么

### 1.1 为什么先分这一刀

（为什么这件事重要，读者不听完也知道）

### 1.2 六类模型：吃什么，吐什么

| 类别 | 吃什么 → 吐什么 | 在豆包里的位置 |
|---|---|---|
| … | … | … |

表 1　六类模型的分工。依 OpenRouter 目录与各产品公开文档整理（2026 年 11 月）。

### 1.3 一个容易混的点：端到端不是第三段

……
```

## 写法

**每一节的第一句回答「这一节解决什么疑问」**，不要上来就摆结论。

```markdown
❌ 端到端语音是另一条技术路径。
✅ 如果按了「打电话」，事后想找一份「它到底听成了什么」的文字记录，会找不到。
   这不是功能没做，是这条路本身不产生文字。
```

**表格后面必须有出处。** 一行小字，写清数据从哪来、什么时候取的。听众里总有人会去核。

**允许展开讲台上没讲的部分。** 清单里标了 `不上台` 的内容，在这里展开——这是材料存在的主要理由。

**不写依赖现场的指代**：不写「刚才那个例子」「上面那页」，一律写「前一节提到的……」。

**每个专业词第一次出现时给一句解释**，不要假设读者听过讲。

## 长度

| 时长 | 材料字数 | 大约页数（A4，五号） |
|---|---|---|
| 20 分钟 | 4–6 千 | 8–12 |
| 45 分钟 | 8–12 千 | 16–24 |
| 90 分钟 | 1.5–3 万 | 30–50 |

材料通常是讲稿的 **1.2–1.5 倍**。少于讲稿，说明你没展开；超过 2 倍，说明跑题了。

## 转成网页

`scripts/handout.py` 把 `handout.md` 转成单文件 html：单栏、可打印、手机可读、带自动目录。

```bash
python3 scripts/handout.py handout.md -o handout.html
```

支持：标题、段落、列表、表格、引用、代码、粗体、链接、图片、分隔线。
**不支持**：脚注语法、数学公式。要公式就写进 `<span class="math">` 或改用 slides 的 KaTeX 方案。

## 打印

材料与讲稿都走同一条打印链（本机 Chrome headless，实测 157 版可用 `@page` 页边注）：

```bash
CH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$CH" --headless=new --disable-gpu --no-sandbox \
      --print-to-pdf=handout.pdf --no-pdf-header-footer handout.html
```

- `--no-pdf-header-footer` **不能省**，否则 Chrome 自带页眉页脚叠在 CSS 之上；
- 材料页眉取 md 的 `# ` 标题，`@page:first` 不出，页脚是 `当前页 / 总页`；
- 表格允许跨页（`thead` 重复表头），不要给 `table` 加 `break-inside:avoid`；
- 换机器打印字体回退，页数会变，**页码必须重新打印核对，不要手改**；
- 链接在 PDF 里可点（Chrome 写成 `/Link`+`/URI` 注释），但打印规则会把颜色抹平，
  所以 CSS 给 `a[href^="http"]` / `a[href^="mailto"]` 留一条暗红点线（`.toc a` 例外，保持无色）；
- 裸网址不会变链接，要可点必须写成 `[文字](url)`；手写的 `#锚点` 会静默失效（标题 id 是自动生成的）。

打印后量三项：

```bash
pdftotext -f 1 -l 1 handout.pdf -        # 首页无页眉、有 1 / N
pdftotext -bbox handout.pdf - | grep -c 'xMax'   # 越界词应为 0（右边距 ≈ 51pt）
python3 -c "import re;d=open('handout.pdf','rb').read();print(len(re.findall(rb'/Subtype\s*/Link',d)))"  # 应等于 md 里链接个数
```

- [ ] 没有「待补」「待定」「TODO」
