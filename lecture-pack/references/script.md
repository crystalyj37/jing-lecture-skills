# 讲稿 `script.md`

只给讲者一个人看。判断标准只有一条：**扫一眼能接着说下去**。

## 格式

```markdown
## U2.0 · 先分一刀　[2′]　屏 n1

大家说的「豆包真聪明」，其实是六个模型叠在一起干活。

我先停一下——〔停 2 秒〕你们觉得，画图和聊天，是同一个模型吗？
〔看他们，等两三个反应〕

好，不是。看这张表。

〔切屏 n1，只出第一行〕
最左边这一列，是「吃什么、吐什么」。文字进文字出，这是 LLM，也是大家平时说的那个「大模型」。

〔空格，出 ASR、TTS 两行〕
这两个只做转换，一个把声音变字，一个把字变声。它们不是「大模型」，规模小得多。

〔空格，出 S2S〕
第三个要特别注意——按「打电话」，语音直接进、语音直接出，中间不落文字。

这意味着什么？事后没有一份「它听成了什么」的文字记录。要留痕、要审核，就得走刚才那个三段式。

〔切屏 n2，链条逐段出〕
所以一次语音问答，实际是三个模型接力……

〔收口〕
一句话：先问这是哪一类模型，再问它强不强。类别不对，比较就没有意义。
```

## 三类标记

| 标记 | 写什么 | 例 |
|---|---|---|
| `〔停 n 秒〕` | 真的要停的地方 | `〔停 2 秒〕` 让刚说的那句落地 |
| `〔切屏 xxx〕` `〔空格〕` | 手上动作，跟 slides 对得上 | `〔切屏 n1，只出第一行〕` |
| `〔看他们〕` `〔举手〕` | 与台下互动 | `〔举手，数一下大概几个人〕` |

另有两类预案，写在单元末尾，不打断正文：

```markdown
〔若有人问「那本地部署呢」〕
一句话带过：本地部署换的是「跑在哪」，不改变它是哪一类模型。想深入，会后单独说。

〔若超时 3 分钟以上〕
砍掉 S2S 的展开，只留一句「打电话走的是另一条路」。
```

## 写法

**要写成能念的句子。** 主谓宾齐全，一句话一个意思。

| 别写 | 写成 |
|---|---|
| 本单元旨在阐明模型分类的必要性 | 为什么非要先分类？因为不分，后面全错 |
| 如上表所示，六类模型…… | 看这张表，六行 |
| 该产品具备多模态能力 | 它能看图，也能画图 |
| 值得注意的是 | （删掉） |

**一段不超过 4 行。** 超过就是你还没想清楚，写成两段。

**每个单元必须有收口句**，并且跟内容清单里的 `收口` 一字不差。
那句是全场唯一要让人记住的话，不能每次讲都不一样。

## 时间

每个单元标题后写 `[n′]`，跟清单一致。讲稿正文按 240 字/分钟估：

- 一个 `[2′]` 的单元 ≈ 480 字正文
- 超 20% 就是写多了，现场一定讲不完
- `crosscheck.py` 会按单元算字数并报超时的段

## 通读检查

写完一定出声读一遍，只改三样：

1. **读不顺的地方**——多半是书面语混进来了，换成口语
2. **一口气说不完的句子**——断开
3. **自己会卡壳的词**——专业术语第一次出现时，加半句解释

读的时候掐表。**你读一遍用的时间 × 1.2 ≈ 现场时间**（现场要等反应、要看设备）。

## 排成台上用的纸

```bash
python3 scripts/script.py script.md -o script.html
python3 scripts/script.py script.md -o script.html --one-unit-per-page   # 一单元一页
CH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$CH" --headless=new --disable-gpu --no-sandbox \
      --print-to-pdf=script.pdf --no-pdf-header-footer script.html
```

版式是按「低头扫一眼能接着说」定的，别改：

| 项 | 值 | 为什么 |
|---|---|---|
| 页边距 | A4 20mm | 右侧留手写批注的余地 |
| 正文字号 | 11.5pt / 行高 1.8 | 台上不戴眼镜也看得见 |
| 单栏 | 是 | 双栏视线跳跃，容易看串行 |
| 目录 | 无 | 台上没人翻目录 |
| `〔…〕` | 独段 → 灰底块；句中 → 灰字 | 舞台提示与口播一眼分开 |

**分单元认 `## `，不认 `### `。** 用三级标题分单元，整份会被排成一个单元。

**`[文字](url)` 在讲稿里只保留文字**（`text_inline` 里显式去掉链接，`![图](path)` 变成「［图：说明］」）。
口播不会去点链接；要可点的地址，留给材料那份。所以讲稿 PDF 里没有 `/Link` 注释，这是设计，不是漏了。

打印后量三件事：首页应无页眉、页脚应有 `1 / N`、`pdftotext -bbox` 逐词比右边距（51pt）应为 0 个越界词。

## 公式

讲稿也认 `$$…$$`（独占一段）与 `\(…\)`，和材料同一个渲染器（需要 node，`--no-math` 保留原文）。
但讲稿是念的：台上要说出口的是「标准误等于 σ 除以根号 n」这样的话，公式只在需要对着看的时候放。
