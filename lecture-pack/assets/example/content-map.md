# 内容清单 · 样张：模型分几类

- 受众：高校各学科教师，不要求 AI 基础
- 时长：2 分钟（单单元样张，正式版按此格式扩到 25–40 个单元）
- 一句话目的：让人明白「一个产品里不止一个模型」，以后评价 AI 先问是哪一类
- 产物：handout（详细材料）· deck（slides）· script（讲稿）
- 状态：样张

### U2.0 · 先分一刀：AI 不是一个模型

- 时长：2′
- 断言：豆包不是一个模型，是六类模型叠着用。
- 证据：

  | 类别 | 吃什么 → 吐什么 | 豆包里的哪一环 |
  | --- | --- | --- |
  | 文本模型（LLM） | 文字 → 文字 | 打字提问，返回文字 |
  | 语音识别（ASR） | 声音 → 文字 | 按住说话，先把语音转成文字 |
  | 语音合成（TTS） | 文字 → 声音 | 把回答的文字念出来 |
  | 端到端语音（S2S） | 声音 → 声音 | 按「打电话」，全程语音，不产生文字 |
  | 图像生成（文生图） | 文字 → 图片 | 说「画一张」，输出图片 |
  | 视频生成（Seedance） | 文字或图 → 视频 | 给一张图，输出视频 |

- 例子：按「打电话」走的是 S2S，语音直接进、直接出，中间不落文字；所以事后没有一份「它听成了什么」可查，要留痕就得走 ASR → LLM → TTS 那条三段式。
- 误区：拿聊天模型的表现，去评价「这个 AI 好不好用」。评测对象根本不是同一个东西。
- 收口：先问这是哪一类模型，再问它强不强。类别不对，比较就没有意义。
- 屏：n1, n2
- 不上台：向量模型（embedding）——知识库能搜到你的 pdf，靠的是它，不是聊天模型。只在材料里展开。
- 来源：六类划分依各产品公开文档与 OpenRouter 目录整理，2026 年 11 月。
