# 源稿写法

一份讲稿 = 一个 `.deck.md`，`npm` 式的标记 + 直接写 HTML。构建成单文件 `.html`。

## 文件骨架

```markdown
---
title: 示例分享 · 演示页
---

::: screen id=s0 steps=0 title="零 · 开场"
...
:::

::: screen id=s1 steps=4 title="一 · 六个术语"
...
:::
```

`---` 包起来的头部只有 `title` 有用（写进 `<title>`）。屏的顺序就是放映顺序。

## 屏块

```
::: screen id=<锚点> steps=<步数> title="<目录与底栏用的名字>"
```

| 属性 | 必填 | 说明 |
|---|---|---|
| `id` | 建议 | 锚点，目录跳转用；不写则用 `s<序号>` |
| `title` | **必填** | 底栏与目录显示的文字，形如「二 · 模型分几类」 |
| `steps` | 有分步才写 | 本屏要点几次才走完；等于屏内最大 `data-step` |

**一条硬规则**：`steps` 必须等于屏内 `data-step` 的最大值。
写大了，最后要多按几次空翻；写小了，最后一步永远出不来。`audit.py` 会报这两种错。

## 四种内层块

### 演讲者备注 `::: note`

```markdown
::: note
先别急着讲模型。让他们把码扫了，第四节要用。
这句是**口头补充**，不上屏。
:::
```

- 只在按 `S` 拉出的右侧面板里出现，**放映画面里不显示**
- 可用 `**粗体**`、`- 列表`
- 写「要说什么、别说什么、大概几分钟」，不要抄屏上的字
- 每屏都该有一条；没有备注的屏，讲的时候容易自由发挥跑题

### Markdown 片段 `::: md`

```markdown
::: md
- 为什么要改：课堂里那三个具体问题
- 怎么改：一节课的最小改动
- 改完怎么验：两个可观察的信号
:::
```

只支持段落、`- ` 无序列表、`**粗体**`、`` `代码` ``。**要排版就别用它**，直接写 HTML。

### 公式 `::: fml`

```markdown
::: fml
\bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i | 样本均值
\mathrm{SE}(\bar{x})=\frac{\sigma}{\sqrt{n}} | 标准误
:::
```

- 一行一条，写法是 `LaTeX | 说明`，说明可省略
- 说明里要提符号就用行内公式：`置换检验里 \(\hat p\) 的标准误`。屏内 HTML 的导语、图注、
  卡片标题里同样可以写 `\(...\)`，构建时统一排版
- **不要直接打 `p̂`**——中文字体里组合变音符号会盖歪；**也不要直接打 `√`**——它不会盖住
  被开方的内容，`√n` 的横线是缺的。两种都会被 `audit.py` 扫出来
- 构建时用 KaTeX 排好，产物里是静态 HTML——**不要手搓 `<sub><sup>`**
- 构建需要 `node`；产物不需要，仍然是单文件离线可开
- 写错公式时 build 会指出是哪一条、错在哪，退出码 1
- 版式细节见 `references/layouts.md` 第 11 节

### 屏内 HTML

屏块里其余内容一律原样输出。所以：

- 想用哪个版式，照 `references/layouts.md` 整段复制进来改字
- 缩进、换行不影响渲染，但保持两空格缩进方便自己读
- 不要在屏块里写 `<style>` / `<script>`：样式统一在 `deck-shell.html` 里改，
  单屏内联样式只用于一次性微调（如 `style="color:var(--muted)"`）

## 分步的写法

屏上 `steps=3`，正文里三个元素标 `data-step="1/2/3"`：

```html
<div class="tbl">
  <div class="tr th"><span>类别</span><span>吃什么</span></div>
  <div class="tr" data-step="1"><span>文本</span><span>文字 → 文字</span></div>
  <div class="tr" data-step="2"><span>图像</span><span>文字 → 图片</span></div>
  <div class="tr" data-step="3"><span>语音</span><span>声音 → 文字</span></div>
</div>
```

- 步号从 **1** 开始，不能用 0
- 可以多个元素共用一个步号（同时出现）
- 翻过这屏再回来，会记住已经走到第几步

## 构建与体检

```bash
python3 scripts/build.py 课程.deck.md -o 课程.html
python3 scripts/audit.py 课程.html
```

`audit.py` 退出码非 0 就不要交付。它查的是：屏 id 重复、steps 与 data-step 不自洽、
表格列数不一致、`data-title` 为空、图片没内嵌、占位符没替换、标记没闭合、
公式渲染失败或缺字体、屏内用了壳里没有的类名（warn，`--strict` 时 error）。

要交 PDF：`python3 scripts/pdf.py 课程.html`（每屏一页，`--steps` 一步一页），适用场景与边界见 SKILL.md「导出 PDF」。

## 放映键位

| 键 | 作用 |
|---|---|
| `→` `空格` `PageDown` | 下一步（先出本屏的行，出完再翻屏） |
| `←` `PageUp` | 退一步 |
| `N` `↓` `Enter` | 直接翻到下一屏（不走分步） |
| `S` | **演讲者备注面板**（同一块屏右侧拉出，再按收起；镜像投屏时观众也看得见） |
| `P` | **讲者窗口**（第二个窗口：当前屏、下一屏、备注、计时，翻页双向同步；扩展屏时用） |
| `B` | 黑屏 |
| `T` | 计时 |
| `G` | 目录浮层 |
| `R` | 阅读模式 / 演示模式 |
| `F` | 全屏 |
| `?` | 帮助 |
| `Esc` | 关掉所有浮层 |

阅读模式给的是「课后能读的版本」：所有分步一次性展开，`.deep` 细读块全开，
侧栏出现完整目录。链接地址加 `?mode=read` 可直接进这个模式。

## 常见写法错误

| 现象 | 原因 |
|---|---|
| 底栏显示 `undefined` | 屏块少写 `title=` |
| 按空格到最后一步就不动了 | `steps` 比最大 `data-step` 大 |
| 某一步永远不出现 | `data-step` 比 `steps` 大，或写成了 `0` |
| 表格列错位 | 某行 `span` 少一个 |
| 整屏字变成裸文字 | class 名写错（如 `tbl` 写成 `table`）；`audit.py` 会提示「未知类名 .table，是不是 .tbl？」 |
| 公式挤成一团、符号错位 | 用了 `::: fml` 之外的手写 `<sub><sup>`，或 KaTeX 样式没注入 |
| build 报「有 N 条公式写错了」 | LaTeX 拼错；按提示里的命令名改 |
| 打开是空白 | 不是 `file://` 打开，或 `<script>` 被编辑器改坏 |
